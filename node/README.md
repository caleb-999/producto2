# Node.js Number Conversion

This directory contains 3 versions of number conversion applications in Node.js.

## Version 1
Consumes the SOAP service directly to convert numbers to words.

### Installation
```bash
npm install
```

### Usage
```bash
node version1.js 10
```

## Version 2
Consumes the SOAP service and translates the result from English to Spanish.

### Installation
```bash
npm install
```

### Usage
```bash
node version2.js 10
```

## Version 3
Converts numbers to words in Spanish using native Node.js libraries.

### Installation
```bash
npm install
```

### Usage
```bash
node version3.js 10
```
