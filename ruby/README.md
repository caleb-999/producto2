# Ruby Number Conversion

This directory contains 3 versions of number conversion applications in Ruby.

## Version 1
Consumes the SOAP service directly to convert numbers to words.

### Installation
```bash
bundle install
```

### Usage
```bash
ruby version1.rb 10
```

## Version 2
Consumes the SOAP service and translates the result from English to Spanish.

### Installation
```bash
bundle install
```

### Usage
```bash
ruby version2.rb 10
```

## Version 3
Converts numbers to words in Spanish using native Ruby libraries.

### Installation
```bash
bundle install
```

### Usage
```bash
ruby version3.rb 10
```
